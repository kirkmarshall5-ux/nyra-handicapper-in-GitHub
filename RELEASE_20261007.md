# October 7 rankings and context release

Version: V44C-data-integrity-rankings-20261007-v1.

Figures at 130 or above require explicit source review; unsupported or missing core inputs retain whole-race PASS. V4.4c weights and adjustments are unchanged. The locked historical engine remains available as the control; the release imports the tested corrected-input module.

The PP tab displays provisional source-call style, condition matches, prior performance text, workouts and pedigree. Actual gate remains unknown unless separately source-verified; program number never becomes gate. Days since latest figure is labeled separately from actual layoff. Prior opposition remains unavailable rather than fabricated. No context bonus is active.

Best Value and automatic betting remain disabled because whole-field probability calibration failed its diagnostic gate. Morning lines are reference prices only. The existing quote recorder retains live source, timestamp, scratch/surface attestations and ranking snapshot; it now records the actual rating version.

Old saved cards require re-upload under the new parser/storage version. Legacy storage is preserved. No private PDFs or horse-level historical audit datasets are shipped in this release.

Validation: 105 synthetic/regression tests; 15 complete PDF roundtrips, 138 races, 1,345 declared entrants, 95 rateable races and 43 PASS decisions, zero ranking or identity/morning-line/figure mismatches against the data-corrected control. Browser verification and deployment results are recorded separately in the private release report.
